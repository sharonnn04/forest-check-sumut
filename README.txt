# Forest Check Sumatera Utara

Forest Check Sumatera Utara adalah aplikasi berbasis Web GIS yang digunakan untuk melakukan pemeriksaan lokasi terhadap kawasan hutan, wilayah administrasi, dan informasi spasial terkait di Provinsi Sumatera Utara.

Aplikasi ini dikembangkan sebagai sistem pemeriksaan lokasi berbasis koordinat dan peta interaktif.

## Fitur Utama

- Pencarian lokasi berdasarkan alamat
- Pencarian berdasarkan koordinat Latitude dan Longitude
- Input koordinat dalam format DMS
- Pemilihan titik langsung melalui peta
- Dukungan link lokasi Google Maps
- Pemeriksaan wilayah administrasi
- Pemeriksaan kelas kawasan hutan
- Informasi PIPPIB
- Peta interaktif berbasis Leaflet
- Riwayat pemeriksaan pengguna
- Sistem login dan registrasi
- Dashboard pengguna
- Dashboard administrator
- Pembatasan penggunaan / rate limit

## Sumber Data

1. Peta Perkembangan Pengukuhan Kawasan Hutan Provinsi Sumatra Utara Nomor 11580 Tahun 2025 tanggal 10 Desember 2025.
2. Peta Indikatif Penundaan Pemberian Izin Baru Revisi Semester Pertama Tahun 2026.
3. Data batas administrasi Provinsi Sumatera Utara.

## Catatan Penggunaan

Hasil pemeriksaan pada aplikasi digunakan sebagai informasi awal berdasarkan data spasial yang tersedia pada sistem.

Untuk kebutuhan yang bersifat resmi, administratif, atau memiliki konsekuensi hukum, pengguna disarankan melakukan verifikasi lebih lanjut kepada instansi yang berwenang.

## Keamanan

Informasi sensitif seperti:

- API secret
- database password
- service role key
- access token
- private key
- credential administrator

tidak disimpan di repository publik.

Konfigurasi sensitif ditempatkan pada layanan backend dan environment yang terpisah dari source code publik.
